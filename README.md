# Instructor Effectiveness Modeling

## Overview
This project analyzes instructor effectiveness using learner outcomes, engagement metrics, and feedback data.

## Project Workflow
- Data Loading
- Exploratory Data Analysis (EDA)
- Data Cleaning
- Instructor Effectiveness Score
- Batch-to-Instructor Aggregation
- Random Forest Classification
- Model Evaluation
- Feature Importance Analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
